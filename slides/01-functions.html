What does a function do?

Try the examples below. Change the input, change the rule, and watch the output and graph move together.

A rule you can use or discover

A function is a rule that transforms an input.

Simple definition: a function transforms an input into an output. In mathematical language, it relates one variable to another. Some functions are known; others are unknown and must be inferred from examples.

Known function

Temperature conversion

We know this rule from physics: Celsius can be converted to Fahrenheit exactly.

input: 20 °C→output: 68 °F
F(C) = 9/5 C + 32known rule
Unknown function

Taxi fare

A route app learns a fare rule from past trips: distance goes in, a price comes out.

input: 8 km→output: $28
fare(d) ≈ 3d + 4inferred rule
Unknown function

Area from a side

The rule is not a straight line: doubling a side makes the square four times larger.

input: 5 m→output: 25 m²
area(s) = s²inferred rule
Unknown function

House estimate

We do not know the exact price rule. A model estimates it from many past house sales.

input: 2 × 100 m²→output: $310k
price(s) ≈ 0.8s + 1.5inferred rule

Known or unknown, the shape is the same: input → rule → output. Machine learning is useful when the rule is too complicated to write down by hand, so we let data help us find it.

When the rule is wrong

The model changes its parameters to make smaller mistakes.

A prediction is only useful when it is close to an example. Loss turns “close” into a number we can minimize.

From one example to one update

For the small model ŷ = ax + b, compare the prediction with the known answer.

$$e = \hat y - y$$
$$L(a,b) = \frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2$$
$$\frac{\partial L}{\partial a}=\frac{2}{n}\sum e_i x_i\qquad\frac{\partial L}{\partial b}=\frac{2}{n}\sum e_i$$
$$a_{new}=a-\eta\frac{\partial L}{\partial a}\qquad b_{new}=b-\eta\frac{\partial L}{\partial b}$$
