03 / Train

A batch repeats four operations.

Forward pass → MSE loss → backpropagation → Adam update. One epoch processes every training row once.

1 · forward
2 · loss
3 · backward
4 · update

loss = mean((prediction − price)²)
weight ← weight − rate × gradient

Backpropagation uses the chain rule to find every parameter’s contribution to the error. Adam uses those gradients to change the weights.

04–05 / Test and evaluate

Freeze the model, then measure generalization.

The test set never updates weights. MAE reports a typical miss, RMSE emphasizes large misses, and R² measures explained variation.
